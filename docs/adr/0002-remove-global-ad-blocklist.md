# 移除全局静态广告域名黑名单

原 `ad_domains` 静态 DNR 规则集默认关闭，且阅读期间的会话白名单（仅放行本站域名）已覆盖其效果；非阅读场景不在本产品范围内。故删除域名表、生成脚本、规则文件、manifest 规则集与 popup 开关，网络层只保留会话白名单。

## Considered Options

- **保留但加作用域说明**：被否。它让用户继续面对两个含义相近的广告开关，而它独有的能力（非阅读时拦截）不属于本产品。
- **换成 easylist 等社区规则表**：被否。静态规则表对盗版站「随机子域 + 动态下发」的广告无效，维护成本却落在本仓库。
- **与会话白名单合并成一个开关**：被否。两者作用域不同（会话白名单只在阅读期间且必须精确到本站），合并后无法解释「关掉广告开关为什么跨域请求仍被拦」。

`declarativeNetRequest` 权限保留：会话白名单靠 `updateSessionRules` 实现，本次只删 `declarative_net_request` 静态规则集。
